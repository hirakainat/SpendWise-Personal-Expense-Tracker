# 💸 SpendWise – Personal Expense Tracker

SpendWise is a simple single-page web application that helps users manage and track their daily expenses. Users can add, edit, delete, filter expenses, and view spending summaries through interactive charts.

## 🚀 Features

- ➕ Add new expenses
- ✏️ Edit existing expenses
- 🗑 Delete expenses
- 📋 View all expenses in a table
- 🔍 Filter expenses by:
  - Date range
  - Category
- 📊 Dashboard with expense overview
- 📈 Spending summary with charts
- 💾 Data persistence using Browser Local Storage
- ✅ Form validation for expense entries
- 📱 Responsive design for different screen sizes

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Chart.js
- Browser Local Storage
